# Acme Relay Suite

Synthetic corpus for the Repoise offline lexical evaluation harness.
Docs, TypeScript/JavaScript code and a fake secret live here.

## Layout

- docs/current: current behavior documentation
- docs/plans: proposed work (not yet current behavior)
- docs/decisions: accepted decision records
- src: TypeScript and JavaScript sources
- tests: behavioral tests
- .env: fake credential material that must never be indexed
